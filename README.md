# 🎶 Harmonine

Free desktop music player built with Electron.js. 

![Platform](https://img.shields.io/badge/Platform-Windows-blue)
![Version](https://img.shields.io/badge/Version-1.0.0-green)

![Harmonine](https://i.postimg.cc/sxT5zXtR/image-2026-03-16-014407925.png)

## 📥 Installation

1.  Download the installer from [**this page**](https://badralfezghari.github.io/harmonine/download.html).
2.  Run the installer.

## 🛠️ Built With

*   [Electron.js](https://www.electronjs.org/) - The framework for cross-platform desktop apps.
*   [Node.js](https://nodejs.org/) - JavaScript runtime.
*   [music-metadata](https://github.com/Borewit/music-metadata) - For reading audio metadata.
